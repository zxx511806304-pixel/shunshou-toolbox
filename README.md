# 顺手工具箱

面向日常学习与办公的 Windows 工具箱。解压运行，不登录、不激活，转换、识别与 AI 视频修补在本机处理。当前为 **1.8.3 正式版**，右上角可切换并保存浅色/深色主题，关闭窗口可最小化到系统托盘，左侧栏可搜索工具名称、检查更新与提交反馈。联网工具标注“需联网”，文件不上传到转换服务。各版本变更见 [更新记录](CHANGELOG.md)。

## 运行

支持 Windows 10 2004（19041）及以上、Windows 11；本版为 x64。提供两种包含相同工具功能的完整包：

- **自解压 EXE**：双击 `ShunshouToolbox-1.8.3-win-x64-setup.exe`，选择软件存放位置，确认后解压。默认勾选创建桌面快捷方式。以后运行新版 EXE 可更新同一目录。
- **便携 ZIP**：将 `ShunshouToolbox-1.8.3-win-x64.zip` **完整解压**到可写文件夹，双击 `ShunshouToolbox.exe`。首次正常运行会创建桌面快捷方式；主动删除快捷方式后，不会每次启动都重新生成。不要只复制单个 EXE。

桌面快捷方式指向软件文件夹；创建后仍需保留完整文件夹。自解压 EXE 只部署软件文件和选择的快捷方式，不登记系统卸载项，不需要账号或激活。本地处理与解压更新均可离线完成；视频、字幕链接下载与网页读取需要网络。

默认位置在系统盘当前用户的应用数据目录中，可直接写入，正常部署不请求管理员权限；也可选择其他可写位置。

0.3.0 的全新软件目录只保留四项：`ShunshouToolbox.exe`、`app`、`docs`、`package-manifest.json`。首次正常启动后增加 `data`。运行库、语言资源、图标和工具引擎统一收在 `app`，不再铺满根目录。`app` 内的内容仍是完整软件的一部分，不能单独删除。更新旧版时额外的用户文件会保留，因此原目录可能多于五项。

## 更新

推荐下载新版自解压 EXE 后运行。程序会记住当前用户选择的存放位置；首次升级从旧 ZIP 解压的版本时，可能需要手动选中旧软件所在文件夹。更新前请保存工作并退出工具箱；检测到该目录的软件仍在运行时，会停止更新并提示，不强制结束进程。

更新会先校验完整包，在旁边准备新文件并保留 `data` 和不属于原包的用户文件，再切换目录。旧目录会保留为备份，占用额外磁盘空间。中断后重新运行同一新版 EXE 并选择相同位置，可以检查并恢复未完成的切换。更新完成后，若新版运行中发现问题，旧目录仍可用于人工恢复；本版不自动判断新功能是否正常并回退。

从 ZIP 更新时请使用新文件夹，退出后再迁移完整 `data` 目录及自己存入软件目录的文件，不建议直接覆盖解压。尤其要保留 `data/uninstall-backups` 中的完整性密钥及全部备份文件；工具生成的外部输出也不要删除。

目前两种发布包都是**全量包**，尚无在线自动更新或差分下载。EXE 尚未代码签名。详见 [分发与更新说明](docs/distribution-and-updates.md)。

生成的文件默认保存到 `Documents/ShunshouToolbox/Output`（使用 Windows 实际“文档”位置），也可自行选择位置。软件添加的文件后缀和目录名使用英文，如 `_page001`、`_text`、`Images_...`；保留原输入文件名和 ZIP 内部名称。旧版的“顺手工具箱输出”目录及文件保留原位，不自动搬动或重命名。转换不覆盖原件。批量改名会更改原文件名，执行前展示预览，恢复记录保存在软件目录 `data/rename-history`。

程序使用 S 形青绿色图标和英文入口文件名，软件界面及桌面快捷方式仍显示“顺手工具箱”。新版 EXE 支持从带包清单的旧中文入口版本及 0.2.2 平铺目录升级，并修复本软件拥有的现有快捷方式；不会覆盖同名的无关快捷方式。

## 拖入文件与搜索

将文件拖到窗口内容区，松开即可添加到当前工具；也可以使用“选择文件”。图片转换、图片提取文字、PDF 合并、批量改名支持多个文件；其他工具一次接收一个输入，收到多个时会提示并保留原选择。拖入不会立即开始转换，确认设置后点击“开始处理”。

文件列表展示缩略图、名称和大小，可以逐项移除；移除只取消选择，不删除原文件。PDF 合并支持上移、下移调整顺序。图片转换与文字识别共享批次，文字识别每次处理当前选中的图片；切换其他工具会保留各自输入草稿。

“文件搜索整理”默认查找全部本机磁盘的已索引内容，也可选择单盘或指定文件夹。输入名称后按 Enter 或点击“搜索”。拖入文件夹会设置范围；拖入文件会同时填写所在文件夹与文件名。

搜索统一连接 Everything 本机文件名索引，已有 Everything 时自动复用。没有索引时，同一个“搜索”按钮会请求 Windows 授权启动随包组件、等待索引就绪，再继续查询。首次使用会显示准备较慢的提示，完成后显示“已就绪”。不安装系统服务或开机启动项，打开工具箱时不触发授权；查询范围受索引及排除规则影响，不静默退回慢速全盘扫描。

结果会边查边显示，取消后保留已找到的项目。选择结果查看预览，双击打开；“打开位置”在资源管理器中定位。图片显示缩略图，其他文件和文件夹显示可用的系统缩略图或图标。缩略图按可见行加载，云端占位文件不下载内容。

## PDF 转 Word / PPT

默认“尽量保留版式”：保留页面尺寸、文字位置、可编辑文字的字体/字号/颜色，以及图片、背景和表格线条。Word 使用定位文本框，PPT 使用独立文字对象；插图和表格线条保留为页面图形，尚未重建成可编辑图表或 Word 表格单元格。混合尺寸 PDF 在 PPT 中按统一幻灯片尺寸等比居中。

扫描件使用 OCR 按位置放置可编辑文字，无法保证还原原有图形与字体；复杂遮挡、特殊字形或缺少字体的文档需核对。暂不支持可靠分层的特殊 PDF 会明确提示，可改选“仅提取可编辑文字”。源文件保留，输出同名时自动避让。

## 图片提取文字

打开“图片与文字 → 图片提取文字”，拖入/选择图片或点“粘贴图片”。焦点在图片区域、按钮等位置时，Ctrl+V 可粘贴截图；在文字编辑框内仍按正常方式粘贴文字。添加多张图片时，点选其中一张后点“开始识别”。原图旁直接显示可编辑结果，“复制文字”只复制正文，“保存 TXT”由你选择位置；识别不会自动生成文本文件。未保存的手工修改在换图、清空或退出时会提示。GIF、多页 TIFF 等按首帧/第一页识别。

## 找工具：搜索与最近使用

左侧栏顶部可以直接搜索工具：输入“裁剪”“二维码”“改名”“字幕”“恢复”等关键词即可跳到对应工具，不必记住它属于哪个分类。搜索框为空时只显示**最近使用**；最近使用记录保存在软件目录 `data/tool-usage.json`，只在本机使用。

在“文件搜索整理”里选中搜索结果后，可以点**发送到…**，把文件直接送到压缩、图片格式转换、图片裁剪、图片提取文字、PDF 合并、整理 PDF 页面、批量重命名等工具；格式不符的项目会被跳过并给出提示，原有输入不受影响。

## 图片裁剪

在“图片处理 → 图片裁剪”拖入一张或多张图片。裁剪方式可选**按比例**（1:1 正方形、4:3、3:4、16:9、9:16、2:3 证件照、3:2）或**按像素尺寸**，取景位置支持居中、九宫格四角与四边。点“预览当前图片效果”先用第一张确认效果，再点“开始裁剪”对全部图片套用同一设置。输出保存在新的 `Images_Crop_…` 文件夹，文件名保留原名并附 `_crop`，原图不变；JPEG / WebP 可按“图片质量”控制体积，超出原图尺寸的裁剪会被明确拒绝。

## 截取音视频片段与提取音轨

“音频与视频 → 截取音视频片段”填写起点与终点，支持 `时:分:秒`、`分:秒` 或直接填秒数。**无损复制**不重新编码，秒级速度，起止会落在最近的关键帧；**精确模式**重新编码，可精确到填写的时间。输出 MP4 或 MP3 / M4A / WAV / FLAC，原文件保留，完成后会显示实际时长。“提取音轨”则把视频中的音频单独取出，或把音频转成常用格式，只提供音频格式选项，避免误把音轨转成视频。

## 文本对比

“文字工具 → 文本对比”把两份文本分别粘进左右两栏，点“开始对比”：结果按行显示新增、删除与相同内容，标注两侧行号，可勾选“忽略空格差异”“忽略大小写”，也可以“同时显示相同行”查看上下文。可以复制差异、复制完整对比或保存 TXT。对比完全在本机进行，文本不会上传。

## 二维码

“文字工具 → 二维码”分两块：上半部分输入网址、文字或联系方式，选择边长、纠错级别与留白，点“生成并保存 PNG”保存二维码；下半部分“选择图片”或“粘贴图片”，在本机识别图片中的二维码并显示内容。支持中文与带参数的链接；生成与识别都不联网，图片与内容不上传。

## 整理 PDF 页面

“PDF 处理 → 整理 PDF 页面”选择或拖入一份 PDF 后显示页面列表与每页旋转状态；没有可提取文字和图片的页面会标记为**疑似空白页**（仅是提示，不会自动删除）。可以多选后上移、下移、删除所选页、顺时针旋转 90°，或一键标记全部疑似空白页，再点“生成新 PDF”。也可以“重新读取 / 恢复到原始”撤销刚才的调整。输出为新文件（原名加 `_pages`），源 PDF 保留；最后一页不允许被删除。

## 解压 7z / RAR

“压缩与打包 → 解压 7z / RAR”支持 .7z、.rar、.zip、.tar、.cab：解压前先列出条目并检查总大小、条目数量、路径与链接，解压后再核对结果目录，解压到以“原名_extracted”命名的新文件夹，原压缩包保留。含符号链接或硬链接的压缩包会明确拒绝（Windows 上创建链接需要额外权限，也可能指向目录外）。随包 7-Zip 26.03 只是解压引擎，本版**不创建** .7z 或 .rar，ZIP 相关操作仍在原有工具中完成。

## 链接提取文字

在“图片与文字 → 链接提取文字”粘贴文章或小说章节地址，加载后先在网页预览里确认内容，点“提取正文”即可得到可编辑文字：保留段落顺序，去掉导航、页脚、脚本和隐藏文本。识别到登录、验证、付费或只有试读的页面时会说明原因，不会用半截正文冒充成功。结果可以“复制文字”，或“保存 TXT”——TXT 第一行是标题，末尾注明来源网址，同名文件自动避让，不会覆盖上次输出。也可以点“网页预览”看原页，或“识别当前画面”把当前可见画面交给本机文字识别。

此功能需联网读取网页，文字提取在本机完成。使用独立私密 WebView2 会话，不读取浏览器已有登录状态，因此需要登录、付费或验证码的内容无法绕过。部分网站把正文换成特殊字形（例如番茄小说），直接复制会乱码，工具会明确提示改用“识别当前画面”。网页自身也可能拒绝自动化访问（例如小红书），这时会报告加载失败。

1.1.0 实际抽查的公开页面：起点中文网、晋江文学城、纵横小说、17K 的章节页，以及少数派、阮一峰的网络日志、MDN 文档都能提取正文；番茄小说因特殊字形被拒绝，抖音视频页与小红书笔记不在正文提取范围内。网站改版或反爬策略会变化，支持范围以你当时的实际结果为准。记录见 [1.1.0 验证](docs/validation-1.1.0.md)。

## 特殊字符库

“图片与文字 → 特殊字符库”收录 22 组、557 个日常符号，按“最常用 → 常用 → 较少使用”排列：勾叉与清单、常用箭头、文案标点、括号引号、金额与单位、带圈数字、几何图形、运算比较、装饰星花、联系提示、上标下标、版权脚注、分数、罗马数字、扩展箭头、其他货币、希腊字母、集合与高阶数学、几何工程与键盘、制表框线与阴影、音乐棋类等。

点击任意字符立即复制到剪贴板，顶部回显“当前字符”和“已复制：名称 符号 U+编码”，便于确认复制的到底是哪个符号。查找框支持字符本身、中文名称（如“勾号”）、分组名（如“箭头”）或编码（如“2713”）；“显示全部”一键回到完整列表。部分图形会随字体或目标软件显示不同，以字符名称和编码为准。此功能完全在本机离线使用，不需要联网。

## 开机自启动

左侧栏底部提供“开机自启动”开关，默认关闭，你可以随时打开或关闭。开启后会在当前用户的开机启动项写入一条指向本软件的记录（附带最小化参数）：下次开机后工具箱以最小化窗口启动，点击任务栏图标即可使用，不打断开机过程。此设置不需要管理员权限，也不安装系统服务或驱动。

关闭开关会立即删除这条记录。若之后把软件目录移动到别的位置，下次正常运行时会把启动项更新为当前位置；软件不会在开关关闭时自行创建启动项。如果系统里已经存在同名的、但不属于本软件的启动项，工具箱只会提示并说明，开启后才会改用它指向当前这份软件。

## 屏幕录制

在“音频与视频 → 屏幕录制”选择显示器，录制整个屏幕或拖框自选区域。默认高清、最高 1080p、30 FPS；可选高画质、小体积预设，或自定义分辨率、1–120 FPS、视频码率（Mbps）、AAC 音频码率与优先硬件编码。输出保持比例且不放大；超出设备编码能力时会明确失败。码率是目标编码参数，不保证实际文件大小等于理论值。

系统声音和麦克风独立开关，麦克风首次默认关闭；高级设置可选择具体音频设备。设备当前静音会显示提示。点击“开始录制”后按倒计时开始，使用浮动控制条或 Ctrl+Alt+F9 暂停 / 继续、Ctrl+Alt+F10 停止并保存。暂停不计入录制时长；退出时会先询问是否停止保存。浮动条仅在系统支持排除捕获时显示；否则保留主窗口或快捷键操作。不会自动开启录制。

视频保存为本地 MP4，默认 `Documents/ShunshouToolbox/Output/Recordings`，每次生成新文件。多屏选择使用物理像素，区域限制在一块屏幕内；锁屏、显示器或音频设备断开、编码器能力等可能中断录制。软件不上传录制内容，不随系统启动采集。

## 视频下载与局部修补

“音频与视频 → 链接下载视频”中粘贴公开视频网页地址，解析后选择画质并下载。网站支持范围会随网站变化；需要账号、付费权限、验证码或 DRM 的视频不会绕过限制。

“音频与视频 → 下载视频字幕”中粘贴链接，按 Enter 读取网站提供的字幕，再选择语言并保存。默认优先选择现有中文字幕，列表区分网站字幕和自动字幕。SRT、VTT 保留时间轴，TXT 便于复制整理；可用语言由网站提供，不包含独立的云端翻译或语音转录服务。

“视频水印处理”中选择本地视频，在画面上框选区域，选择处理引擎，再预览 3 秒或导出完整视频：

- **常规处理**：模糊、纯色遮盖、裁剪保留区域或邻域修补。无需 AI 推理。
- **轻量 AI 修补**：MI-GAN 对选区逐帧补全，适合小块固定标记。移动背景可能闪烁。
- **深度 AI 修补**：STTN 同时参考相邻画面，适合尝试更复杂的运动背景。处理更慢，效果仍需预览比较。

AI 生成的是估计内容，不能保证还原被遮挡的原图。AI 档可选择“自动选择”“CPU”或“显卡加速”；自动模式优先尝试 DirectML，不能运行时回退 CPU，并显示实际运行方式。显式选择显卡时，失败会提示，不默默改用 CPU。CPU 也能运行，速度取决于设备、视频长度和画面尺寸。只导出新的 MP4，不覆盖输入视频。

两套 AI 模型已包含在完整安装包中，不需要首次下载，也不需要账号或 API 密钥。

右上角 `··· → 关于顺手工具箱` 按功能列出第三方项目、版本、许可与原链接；详细许可证原文随包保留。以后增加组件时，由构建流程同步来源目录。

## 网页转 PDF

在“PDF 处理 → 网页转 PDF”粘贴完整网址，按 Enter 加载，确认预览后点击“保存 PDF”。默认使用纵向 A4、保留背景，直接存入默认输出目录；需要时可选择横向或其他目录。同名文件自动避让，网页文字通常可以选择复制，分页遵循网页的打印样式；懒加载内容须先在预览中滚动加载。

此功能需联网读取网页，PDF 在本机生成。使用独立私密 WebView2 会话，不读取 Chrome / Edge 的已有登录资料；缺少运行库时页面会提供 Microsoft 官方安装入口。网页可能限制访问，未成功加载时不会保存错误页面。来源见 [网页组件说明](docs/WebPdfComponents.md)。

## 软件卸载

按名称或发布者查找软件，选择后查看版本、位置等信息，点击正常卸载。需要管理员权限时，在明确操作后新开管理员窗口并选中该软件，仍需再次点击卸载；不会自动运行卸载命令。系统卸载器可能另开窗口，取消等待不会强行终止正在修改系统的安装器。

卸载后可“检查残留”；卸载器缺失或损坏时可检查关联文件及卸载列表记录。扫描结果默认全部不选，核对路径与用途后勾选清理。目录、同名数据和注册表设置可能包含个人偏好或数据，因此需要逐项确认。先完成并校验全部备份，再处理选中项；备份保存在软件目录 `data/uninstall-backups`，可从备份列表恢复。不要删除或单独移动备份目录内的完整性密钥文件。

关联扫描采用保守范围：登记的独立安装目录、准确同名的数据目录及软件专属注册表项。系统/共享根目录、用户文档、目录链接、云占位文件，以及与其他软件共用的位置会跳过；单目录超过 2 GB 或 20,000 个条目也会跳过。清理前重新核验扫描内容；恢复不会覆盖后来新增或修改的文件。当前用户 Windows 应用交由 Windows 卸载和管理数据。本模块不是 Geek/BCU 全部清理能力的复制，不保证发现所有残留、修复驱动/服务，或代替每个软件的专用卸载器。

## 误删恢复

打开“文件搜索整理 → 误删恢复”，选择原文件所在磁盘或原始磁盘镜像，再选择保存位置。恢复实际磁盘时，保存位置必须在另一个卷上，建议使用移动硬盘，并从另一个磁盘运行工具箱。“综合查找”依次检查当前用户回收站、可读的 NTFS 删除记录和文件内容；单独选择一种方式可以缩小范围。读取实际磁盘的删除记录或深度扫描需要管理员权限。

找到候选后，输入文件名或 `jpg, pdf, docx` 等格式筛选，选择文件查看图片或文字预览，点击“恢复选中”保存副本。恢复副本平铺保存在所选文件夹，遇到同名会安全改名；显示的原路径只用于参考，不会据此写回旧位置。回收站及备份中的原件保留。“已有备份”读取你手动选择的现有备份文件夹，不会自动寻找历史版本。

NTFS 记录完整时可能保留原名；深度扫描按文件内容寻找，通常没有原名和目录，也可能找到当前仍存在的文件。综合结果仅隐藏与有名候选内容哈希相同的匿名深扫副本，磁盘上的候选文件保留。PNG / JPG / BMP / GIF 图片预览后可识别图中文字，识别只作用于当前图片。

扫描会把候选、诊断与会话文件保存到选定位置；停止后保留已找到的候选。预览可打开或文件长度一致，不等于内容完整。已覆盖数据、SSD TRIM、损坏记录不能保证恢复；当前 NTFS 路线不处理压缩、加密、稀疏文件、跨记录属性列表或额外数据流。具体范围和实现见 [恢复说明](docs/recovery-engine.md)。

## 准确理解结果

- 20 MB 按 20,000,000 字节计算，并留 2.5% 余量。核验的是最终 ZIP/媒体文件实际大小。无法达标会明确提示，不删除文件或截短视频凑大小。
- ZIP 目标压缩会优化 JPG / PNG / WebP；其他格式原样保留。先尝试无损，再按勾选项调整质量和尺寸，综合文件体积与图片特征分配压缩幅度。PNG 不会为凑大小而偷偷改为 JPG。无损不能保证固定压缩比例，有损结果需要检查。
- PDF 转 Word / PPT 默认尽量保留版式，文字可编辑，页面图形和表格线条保留；表格单元格、图表和公式尚未重建成对应的可编辑对象。扫描页按位置 OCR，特殊字体、复杂遮挡或版式需核对；也可手动选择仅提取文字。
- PDF 长图保持所选 DPI。非常长的 PNG 可能超过某些看图软件的显示上限，建议同时保存逐页图片。
- 搜索使用 Everything 本机索引，首次使用需要建立索引；已连接的索引及排除规则决定可搜索范围。最多显示前 10,000 项，超过后可缩小范围；内置文档全文预览及 7z/RAR 尚未包含在本版。
- 不承诺全部格式可转换，也不把有损压缩称作无损；已损失的音质/画质不能通过转换恢复。
- MP3 / M4A / MP4 使用有损编码。初版转换主要音视频轨道；额外音轨和字幕不保留。FLAC 保留整数音频精度；浮点音频和当前编码器无法完整保留的 32 位整数音频会明确拒绝，建议使用 WAV。

## 开发

使用 .NET SDK 10.0.401、Windows x64。UI 与处理服务分别位于 `src/Shunshou.App`、`src/Shunshou.Core`；`Shunshou.Deployment` 负责包校验与目录切换，`Shunshou.DesktopIntegration` 负责快捷方式和运行标记，`Shunshou.Setup` 提供独立解压界面，`Shunshou.Launcher` 是根目录的轻量原生启动器。真实生成样本的集成测试位于 `tests` 下。

```powershell
dotnet restore Shunshou.slnx
pwsh ./scripts/Download-Runtime.ps1
pwsh ./scripts/Download-Everything.ps1
pwsh ./scripts/Download-OcrModels.ps1
pwsh ./scripts/Download-Recovery.ps1
pwsh ./scripts/Get-VideoDownloadRuntime.ps1
pwsh ./scripts/Build-SttnModel.ps1 -Python 'C:/path/to/python312/python.exe'
dotnet build Shunshou.slnx -c Release
dotnet run --project tests/Shunshou.SmokeTests -c Release -- artifacts/smoke
dotnet run --project tests/Shunshou.Deployment.Tests -c Release -- artifacts/deployment
dotnet run --project tests/Shunshou.DesktopIntegration.Tests -c Release -- artifacts/desktop-integration
pwsh ./scripts/Test-Launcher.ps1
pwsh ./scripts/Build-Portable.ps1
pwsh ./scripts/Build-Setup.ps1
pwsh ./scripts/Build-RecoverySources.ps1
```

可用 `--compression`、`--images`、`--pdf`、`--ocr`、`--media`、`--files`、`--inputs`、`--uninstall`、`--recovery`、`--characters` 单独运行测试组。`--characters` 只检查随包字符库（22 组 557 个字符、名称/编码/分组查找、损坏数据拒绝），不需要联网。图片、媒体和恢复镜像样本由测试生成，不使用用户文件。UI 支持 `--screenshot-dir <目录> --theme light|dark`，以及 `--verify-ui <测试夹具目录> <输出目录>`，验证真实 WinUI 中的输入、搜索、缩略图、OCR 编辑、恢复和卸载界面；`--verify-v110 <输出目录> [站点清单.json]` 校验特殊字符库、开机自启动开关和链接提取文字（含真实网站抽查）。卸载测试使用生成的文件和内存注册表/进程执行器，不卸载测试电脑上的实际软件；启动项测试使用内存存储，不改动测试电脑的开机启动项。

下载脚本校验固定 SHA256。FFmpeg 使用固定 autobuild 资产，Microsoft C++ 运行库从官方签名再分发包中提取，构建过程中不安装系统运行库。OCR 模型需要完成 NuGet 还原后单独下载；恢复组件及对应源码依赖固定版本清单。准备恢复源码使用 Python 3.14 或以上的标准库解包支持；原生启动器使用固定 Zig 0.15.2 构建。这些开发工具不随成品安装，运行成品无需联网。

STTN 首次导出另外使用 Python 3.12 x64 的隔离环境；固定 PyTorch、ONNX 与全部 wheel 哈希，不安装到全局 Python。`Build-SttnModel.ps1` 负责获取固定源码/权重、导出并核验模型、准备轻量模型和许可证；已验证模型可复用。开发用 PyTorch 不随软件分发。详见 [AI 组件说明](docs/AiInpaintComponents.md)。

便携构建同时携带 .NET、Windows App SDK、本地 C++ 运行库、FFmpeg、OCR 模型和 PhotoRec，生成文件哈希清单与静态 DLL 依赖报告。自解压构建嵌入现有便携 ZIP 及其 SHA256 元数据，包含自身需要的 .NET 运行库，产出独立 EXE。已有同版本输出时脚本会拒绝覆盖；使用新的版本号或指定新的 `-OutputRoot`。构建成功仍需要对最终目录实际启动和离线验证。

恢复组件的完整对应源码与构建资料另打包为 `RecoverySources-1.8.3.zip`，与软件二进制从同一下载位置提供；它不放进安装目录，运行软件不需要解压源码包。版本、许可和校验对应关系见 [恢复源码说明](docs/RecoverySources.md)。
