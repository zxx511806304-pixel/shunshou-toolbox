# 0.2.0 更新验证

日期：2026-09-10。Windows 10 x64，.NET SDK 10.0.401。所有修改文件的测试使用独立生成夹具；未卸载真实软件，未修改系统注册表，未替换用户剪贴板。

## 构建与完整回归

- Release 整体构建：0 警告、0 错误。在线官方 NuGet 漏洞查询：三个项目及传递依赖未发现已知漏洞。初期沙箱网络导致 NU1900，刷新官方索引后已解决。
- 输入草稿、压缩/打包、图像、音频/视频、PDF、OCR、文件搜索/改名、卸载核心完整回归通过。结果：`artifacts/smoke-v020-final`。
- 生成的 116.29 MB JPEG ZIP 压到 18.41 MB，保留 12 张图片及说明文件的路径，保留像素尺寸，有损质量为 30；并非保证任意 100 MB 包都能达到 20 MB。
- 100 页 A4 / 150 DPI 长图输出 1240 × 175500，验证 PNG CRC 和完整解压。可编辑 Word/PPT、扫描件 OCR、音视频时长与无损音频采样精度回归通过。
- TIFF 真实多页样本只识别第一页，中英文与数字正确；原件哈希不变，超大尺寸头在解码前拒绝。

## 实际 WinUI 工作流

- 工具按钮直接展开，图片转换/OCR 共享批次，主选图片、单项移除和自动滚入可视区。
- 原图有界预览、真实离线 OCR、编辑、取消放弃修改、只复制正文、明确保存 TXT，以及保留空行的 Windows 换行处理。
- 自建 DataPackage 走图片位图/文件粘贴路径，不替换系统剪贴板；编辑框内 Ctrl+V 保持文字粘贴。取消晚结果不覆盖当前内容，会话清理不删除原图。
- 搜索默认全盘、生成目录实际搜索、缩略图与选中预览、快速切换、过滤和清空；160 张图片跨五段滚动，离屏位图不累积。
- 卸载页面真实过滤事件、失效卸载器、默认不选候选、取消/确认流程：确认卸载仅调用替代执行器一次；确认清理实际备份并删除两个生成目录，再通过生产恢复方法校验原始文件 SHA256。
- 稳定状态浅色/深色截图检查，复制/保存和清理操作可见；修正了 OCR 成功提示被裁切、卸载复选框多余留白。

本机界面记录：`artifacts/ui-v020-final`；卸载操作详情在其中 `software-fixtures/ui-action-verification.json`。最终便携 ZIP 全新解压后复验记录：`artifacts/package-v020`，包含真实中文入口的 UI、离线引擎与清单哈希检查。

## 卸载核心与边界

- 只读正常用户进程枚举得到 47 个桌面软件及 58 个 Windows 应用，105 个唯一条目。
- 合成目录和内存注册表验证：预览零修改、只清所选、全量备份后删除、备份完整性/篡改、原件变化、共享归属变化、取消、权限不足整批零删除、恢复拒绝覆盖后来内容。
- `artifacts/uninstall-v020-junction-final` 实际验证安装根 junction、子 junction、扫描后新增 junction 拒绝清理，目标内容哈希保持；NTFS 附加数据流目录同样保留。
- 卸载模块采用独立的保守实现，不包含 BCU/Geek 程序；不会自动清理系统服务、驱动、全盘模糊匹配项或所有残留。详见 [卸载实现](uninstaller-engine.md)。备份恢复只覆盖本工具清理的残留，不能撤销第三方卸载器全部动作。
- 未进行真实软件卸载、Store 卸载或 UAC 点击测试；这些修改系统的路径使用注入执行器验证。未使用外部桌面自动化模拟资源管理器拖放手势，也未在干净 Windows 11/多 DPI/高对比度设备上完成验证。
