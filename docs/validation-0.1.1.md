# 0.1.1 更新验证

日期：2026-09-10。Windows 10 x64 / .NET SDK 10.0.401。所有搜索内容与图片均为独立目录内生成的测试资料，不用用户文件跑测试。

## 已通过

- Release 构建：0 警告、0 错误。
- `--inputs`：各工具格式与数量、混合有效无效文件、去重、单项拒收多个、忙碌不改变输入、拖入搜索文件与文件夹、原件哈希保持。
- `--files`：实际本机磁盘列表发现；双范围与重叠范围、渐进批次不重不漏、图片过滤、不可访问位置、取消保留、结果上限、90 层目录、真实目录 junction 不跟随，以及原改名/撤销回归。
- 实际 WinUI `--verify-ui`：窗口拖放注册、输入高亮、共用输入路径在真实控件中的结果；搜索默认全部磁盘、拖入后范围与名称填写、生成文件搜索、列表缩略图、选中预览、快速切换与清空选择。
- JPG / PNG / WebP、纵向图片的 96 / 480 像素缩略图尺寸与比例；18 并发请求、损坏/缺失文件降级、远程和 Offline 路径拒绝、取消、变更后缓存刷新、原件不变。
- 160 张图片跨五段实际滚动，离屏解码位图不累积；每段持有的结果位图不超过 32 项，可回收行正确重新加载。
- 已查看浅色/深色搜索结果、输入状态和拖入高亮图，预览区的“打开”和“打开位置”按钮固定可见。

本机开发检查记录：`artifacts/inputs-v011`、`artifacts/smoke/file-search-v011-final`、`artifacts/ui-v011-final`。包级复验使用 ZIP 全新解压后的中文 EXE，并核对文件清单，记录在 `artifacts/package-v011`。

## 仍需区分的边界

- 已验证多范围遍历与真实本机磁盘发现；没有用用户整块硬盘做全量性能基准。搜索属于实时扫描，没有实现 Everything 式常驻索引，目录很多时耗时更长。
- 实际 WinUI 自检覆盖控件与共享输入逻辑；未用外部桌面自动化模拟资源管理器拖拽手势，也未自动打开用户文件或资源管理器窗口。
- 图片有真实图像预览；其他类型使用现有系统缩略图或文件图标，没有内置 Word/PDF 文档全文阅读器。
- 不可访问的受保护目录、目录链接以及需云端下载的预览内容不会强行访问。
- 0.1.0 核心转换的既有验证见 [初版记录](validation.md)。上一版 GitHub Actions 已运行成功；本版云端运行状态以对应提交的 Actions 为准。
