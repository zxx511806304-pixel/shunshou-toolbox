# 1.1.0 特殊字符库、开机自启动与链接提取文字定向验证

日期：2026-09-21。环境：Windows 10 x64（19045）、.NET SDK 10.0.401、WebView2 运行时 153.0.4234.48。测试资料均为程序合成或公开网页，不使用客户资料。本报告区分真实输出验证、应用视觉检查与仍待覆盖的部分。

## 特殊字符库

- 随包数据 22 组、557 个字符全部载入并渲染到真实 WinUI 界面；每组都有标题、使用频率和条目，组内没有重复字符。
- 名称、编码、分组与字符本身四条查找路径实测：`勾` 命中 ✓、`2713` 命中 ✓、`箭头` 返回「常用箭头」「扩展箭头」两组、`✿` 命中自身；无匹配时显示空状态并保留“显示全部”入口。
- 点击真实按钮后读取系统剪贴板：内容等于该字符；连续点击 ✓、✿ 时剪贴板跟随最后一次点击；顶部“当前字符”和“已复制：花朵 ✿ U+273F”同步更新。
- 窗口从 1220 宽缩到 960 宽时每行列数 15 → 10，恢复后回到 15，说明窄窗口会自动换行而不是横向截断。
- 浅色、深色、切回浅色三种状态的实际界面截图已查看；字符瓦片、状态文字和当前字符框在三态下都清晰可读。
- 独立测试组 `--characters` 另外覆盖：数据损坏、版本不支持、空目录、非 BMP 字符（🀄 = U+1F004）与多字符编码描述。

## 开机自启动

- 通过左侧栏真实开关（不是内部调用）开启：注册表当前用户启动项出现 `"…\ShunshouToolbox.exe" --startup`，带引号以兼容含空格的目录，并附带最小化启动参数。
- 关闭开关后启动项立即消失，界面勾选状态同步复位；校验结束时把注册表恢复到运行前的状态（本次运行前未开启，运行后仍未开启）。
- 勾选状态下已实际查看浅色与深色界面截图，左栏显示“开机自启动”已选，并在底部说明“下次开机后用最小化窗口启动顺手工具箱”。
- 单元测试使用内存存储验证：开启 / 关闭、目录搬家后自动指向当前副本、开关关闭时不会自行创建、同名但不属于本软件的启动项不会被删除、注册表被拒绝写入时报告失败而不是假装成功。
- 未覆盖：真实重启后的实际开机行为、多用户或组策略限制启动项的环境、被安全软件拦截的情形。

## 链接提取文字

- 本地样例页：提取 9 段、550 字，段落顺序完整，导航文字与 `display:none` 隐藏段落都没有出现在结果里；使用私用区字形的页面被明确拒绝，而不是输出乱码；保存 TXT 两次生成两个文件，首个文件保留且末尾带“来源：”网址。
- 真实公开页面抽查 10 个（不登录、不使用浏览器 Cookie）：

| 站点 | 结果 |
| --- | --- |
| 起点中文网 章节页 | 提取成功，2,943 字 / 46 段 |
| 番茄小说 章节页 | 按设计拒绝：正文使用特殊字形，提示改用“识别当前画面” |
| 晋江文学城 章节页 | 提取成功，983 字 / 29 段 |
| 纵横小说 章节页 | 提取成功，5,418 字 / 149 段 |
| 17K 小说 章节页 | 提取成功，3,207 字 / 121 段（Mozilla Readability） |
| 少数派 文章 | 提取成功，1,929 字 / 70 段 |
| 阮一峰的网络日志 | 提取成功，14,583 字 / 544 段 |
| MDN 文档 | 提取成功，965 字 / 36 段 |
| 抖音 视频页 | 不适用：页面为视频且需要登录，工具未输出正文 |
| 小红书 笔记 | 网页拒绝对话（ConnectionAborted），工具报告加载失败 |

  结论：主流中文小说平台中，提供可读 HTML 正文的站点（起点、晋江、纵横、17K）都能直接提取；以特殊字形或反爬保护正文的站点会明确失败并给出替代方式。功能保留，支持范围以实际结果为准。
- 顺带修复一个真实缺陷：网页加载完成后，界面还会收到一次由程序自身写 URL 引发的延迟 `TextChanged`，把“已加载”状态清空，使紧接着点击“提取正文”偶发提示“网页已跳转”。现在只有用户确实改了地址才会清除加载状态；修复后样例页与全部真实站点通过。

## 实际限制

- 只测新增三项及对应界面，未重跑压缩、PDF、OCR、媒体、恢复、卸载等既有功能。
- 链接提取文字依赖网站当时返回的 HTML。网站改版、增加验证码、改为登录或付费阅读后可能失败；不绕过登录、付费与验证码，也不代表可批量下载整本书。
- 特殊字符库中的图形字符会随系统字体与目标软件显示不同，判断依据是工具给出的名称与 U+ 编码；未逐字符在 Word / Excel / 微信等目标软件里比对。
- 未在干净 Windows 10/11 虚拟机、混合 DPI 多屏、高对比度主题下重测；EXE 仍未代码签名。
