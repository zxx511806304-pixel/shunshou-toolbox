# 1.0.1 搜索与 PDF 版式修复

## 已验证

- 搜索原实现每次深度遍历目录，本次改接 Everything + 官方 ES，本地 IPC 查询现有索引。独立定向测试 289 项结果连续五次 315–341 ms（含 ES 进程启动）；实际界面三次全盘查询 279–308 ms。记录见 [索引测试](validation/1.0.1/indexed-search-results.json) 与 [界面测试](validation/1.0.1/ui-results.json)。
- 中文、逗号、空格、正则/查询语法字符按字面名称匹配，图片筛选、文件夹范围、结果上限、取消和索引初始化状态通过。真实查询曾发现编码乱码与无索引属性触发磁盘读取，已修复并重测。
- PDF 专项测试创建含彩色粗体标题、斜体双栏、图片、表格线、嵌套 Form、被图片遮挡的文字、旋转标签、中间空白页及不同尺寸末页的三页文档。默认 DOCX/PPTX 转换通过 Open XML Office 2019 校验，文字可编辑，源文件保持，取消和暂存清理通过。
- LibreOffice 26.2.6 实际渲染两个导出文档并逐页检查；字体、图片、线条、双栏、页数和旋转的验证结果见 [渲染记录](validation/1.0.1/visual-qa.json)。对应示例的水平文字上下位置偏差小于 2 pt。
- 实际搜索和 PDF 界面在 Light → Dark → Light 切换后截图检查；搜索缩略图和选中预览正常。只测相关功能，没有执行全部工具回归。
- 最终打包程序再次运行同一专项界面检查通过，全盘索引查询 290–320 ms；安装 EXE 在独立生成目录完成真实解包及快捷方式流程，未写入用户桌面或注册表。随后仅修正随包旧说明文案，应用二进制保持一致。

## 边界

- 搜索速度来自这台电脑已有的索引；未实测首次 UAC 授权建库、其他电脑或现有 Everything 未索引的目录。已有实例的排除规则继续生效；未索引位置需手动选普通搜索。
- PDF 输出使用定位文字和页面图形层，图表和表格线条尚未重建成可编辑图表/表格单元格。扫描页仅按位置 OCR；复杂部分遮挡和任意旋转不能保证完全还原。内联图像、Type3 等尚不支持的版式会明确提示。
- DOCX/PPTX 的视觉测试使用 LibreOffice；未声称所有 Microsoft Office/WPS 版本显示完全一致。LibreOffice 为解压的开发工具，不随安装包分发。
- 未改动或执行用户机器上的安装升级；未测试首次索引提权、干净电脑及系统高对比度。
